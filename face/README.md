# Serene · Facial Animation Studio

Meshy로 만든 「Serene Portrait」 FBX 모델(얼굴 리그와 블렌드셰이프가 없는 정적 스캔 메시)을 바탕으로 만든 프로그램입니다. 표정을 짓고 말하는 WebGL / Three.js 실시간 3D 캐릭터를 실행합니다.

---

## 1. 실행 방법

| 버전 | 방법 |
|---|---|
| **단일 HTML** | `dist/serene_face_studio_single.html` 파일을 더블클릭하면 됩니다(file:// 에서도 동작). 3D 모델과 1K/2K 텍스처가 파일 안에 포함되어 있습니다. |
| **전체 버전** (4K/8K 텍스처, 소스 수정용) | 폴더에서 `python -m http.server 8000` 또는 `npx serve` 를 실행하고 `http://localhost:8000` 에 접속하세요. 브라우저가 file:// 에서 모듈과 GLB 로딩을 차단하므로 로컬 서버가 필요합니다. |

권장 환경은 WebGL2를 지원하는 최신 Chrome, Edge, Safari 17 이상, Firefox입니다. 한국어 음성은 OS에 설치된 음성을 사용합니다. Windows는 'Microsoft Heami / SunHi Online', macOS와 iOS는 'Yuna', Android Chrome은 'Google 한국어'를 씁니다.

## 3. 원본 모델 분석과 처리 과정

| 항목 | 원본 FBX | 결과 |
|---|---|---|
| 버텍스 / 폴리곤 | 537,205 / 1,074,502 | 106,843 (UV 분할 포함) / 179,116 |
| 얼굴 밀도 | — | 얼굴 영역은 원본 대비 약 62%, 머리·목은 약 9%로 줄여 **얼굴 디테일을 우선 보존** (Blender 가중치 Decimate) |
| 컬러 | 8192² PNG 71MB | WebP 8K/4K/2K/1K |
| Normal / Metallic / Roughness | 4096² | Normal WebP, Metal+Rough는 ORM 1장으로 합침(G=거칠기, B=금속성) |
| 리깅 / 블렌드셰이프 | 없음 | 본 3개(root/neck/head) + 모프 타깃 50개 (아래 참고) |

- 원본 ZIP과 FBX는 **수정하지 않았습니다**. 원본 FBX의 SHA-256 값은 `83538eb5587eb31147cb6803e2cb112486593d7832c369d468913c33e0490338` 입니다.
- 이 모델은 얼굴만 있는 **흉상(머리 + 목)** 이고 의상은 없습니다. 헤어는 메시와 텍스처로 이루어져 있으며 그대로 두었습니다.
- 입은 **위아래 입술이 하나의 메시로 붙어 있었고**, 눈은 **안구 없이 피부 텍스처에 그려져** 있었습니다. 그래서 다음 7장의 구조 작업을 했습니다.

## 4. 얼굴 애니메이션 시스템 (`js/rig.js`)

1. **특징점 → 3D**: 눈꺼풀 윤곽, 홍채, 눈썹, 입꼬리, 입술선, 콧볼, 턱 등 약 50개 특징점을 정면 투영 좌표로 정의했습니다. 실행할 때 메시에 레이캐스트해서 3D 위치를 얻습니다.
2. **실제 개구부 생성**
   - 입술선을 따라 위아래 입술 사이 삼각형을 잘라 **실제로 열리는 입**을 만들었습니다. 잘린 경계는 부드러운 입술선 곡선에 맞춰 정렬했습니다.
   - 안쪽 입술(점막) 스트립을 추가했습니다. 다물었을 때는 서로 겹쳐서 입을 밀봉합니다.
   - 눈꺼풀 윤곽 안쪽을 잘라 **3D 안구**를 넣었습니다. 안구 반지름은 눈꼬리에 맞춰 자동으로 맞추고, 눈꺼풀 테두리 스트립을 더했습니다.
3. **블렌드셰이프 (ARKit 52 체계)**: 해부학적 영역 가중치와 부드러운 감쇠를 써서 **실제 버텍스를 변형**합니다.
   - `jawOpen`은 턱관절(TMJ) 축을 기준으로 회전합니다. 입꼬리(modiolus)는 약 45%만 따라가므로 입이 타원형으로 열립니다.
   - 눈 깜빡임은 윗눈꺼풀이 **안구 표면을 따라** 내려옵니다. 중간 지점에 보정 모프(`eyeBlinkArc*`)를 넣어 안구가 눈꺼풀을 뚫지 않게 했습니다.
   - `jawArc`는 턱 회전을 선형 모프로 보간할 때 생기는 오차를 바로잡는 보정 모프입니다.
   - `eyeLook*` 4종(In/Out)과 `tongueOut`은 강체 회전과 이동으로 처리합니다. 안구와 혀는 별도 오브젝트입니다.
4. **입 내부**: 윗니와 아랫니 각 14개, 잇몸, 혀(혀끝 올리기 모프 포함), 구강(내부면 메시)을 넣었습니다. 아랫니와 혀는 턱 회전축에 연결되어 함께 움직입니다.
5. **스키닝**: root, neck, head 본 3개를 씁니다. 목 부분은 가중치를 섞어서 고개를 돌릴 때 목이 자연스럽게 휘어집니다.
6. **GPU 모프 타깃**: three.js 모프 텍스처로 처리합니다. 고사양에서는 모프 노멀을 포함하고, 모바일과 저사양에서는 위치만 씁니다.
7. **캘리브레이션**: 상단의 **캘리브레이션** 버튼을 누르면 정면 직교 뷰에서 특징점을 끌어 조정할 수 있습니다. **리그 재생성**은 약 2초 걸리며, 결과는 localStorage에 저장되고 JSON으로 내보내거나 불러올 수 있습니다.

## 5. 기능 사용법

- **감정 15종**: 왼쪽 패널에서 고릅니다. **혼합 모드**를 켜면 여러 표정에 각각 0~100% 가중치를 줄 수 있습니다. 표정 강도와 전환 시간은 슬라이더로 조절하며, 전환은 임계 감쇠 스프링으로 보간합니다.
- **정밀 제어**: 오른쪽 패널의 19개 슬라이더를 씁니다(더블클릭하면 0으로 돌아갑니다). ARKit 52개 원시 슬라이더, 사용자 프리셋 저장·불러오기·삭제, **Reset**도 이 패널에 있습니다.
- **말하기 모드** (하단)

  | 모드 | 립싱크 표시 | 설명 |
  |---|---|---|
  | 브라우저 음성 | **근사 립싱크** | Web Speech API로 재생합니다. 텍스트에서 음소 타이밍을 추정하고, 단어 경계 이벤트가 오면 다시 맞춥니다. 문장 단위로 끊어서 재생합니다. |
  | (음성 없음) | **무음 미리보기** | 해당 언어 음성이 없을 때 입 모양만 재생합니다. |
  | 오디오 파일 | **오디오 분석** 또는 **정확** | 실제 파형을 분석해 립싱크합니다. 비즘 JSON을 함께 열면 타임스탬프와 정확히 맞춥니다. |
  | 마이크 | 오디오 분석 | 실시간 미러링 |
  | 외부 TTS 서버 | **정확 립싱크** | `server/proxy-server.mjs` 같은 서버가 오디오와 비즘 타임스탬프를 돌려줍니다. |

- **한국어 처리**: 음절을 초성·중성·종성으로 분해하고, 이중모음은 활음과 주모음으로 나누며, 연음을 반영하고, 종성은 대표음으로 바꿉니다. 이렇게 얻은 18개 비즘에 지배도 모델 기반 **동시조음**을 적용합니다. 양순음(ㅁ, ㅂ, ㅍ)은 입술이 반드시 닫히도록 처리했습니다.
- **자동 감정 표현**: 문장마다 감정 키워드(한·영·일), 문장부호, 이모지, 강조어를 분석해 표정과 끄덕임·고개 기울임 같은 제스처를 적용합니다. 분석기를 **AI 엔드포인트**로 바꾸면 서버의 LLM이 판단합니다. 실패하면 내장 규칙으로 돌아갑니다.
- **생체 움직임**: 불규칙한 깜빡임(가끔 두 번 연속), 사카드와 미세 안구 운동, 좌우 눈의 수렴 시선(카메라 또는 마우스 따라보기), 노이즈 기반 고개 움직임, 말하는 중 끄덕임, 호흡, 미세 표정이 있습니다. 모두 랜덤 타이밍입니다.
- **뷰어**: 360° 회전과 확대, 이동(터치 포함), 자동 회전, 정면·측면·후면·45°·얼굴·전체 보기, 카메라 초기화를 지원합니다.
- **피부 톤 / 광택**: 왼쪽 패널 슬라이더. 피부 톤은 0% = 원본, 기본 75% = 밝은 백인 피부(스캔 평균 피부색을 sRGB 241·212·197로 옮기는 채널별 보정 → 주근깨·모공·메이크업 대비 유지). 머리카락은 기하 마스크로 제외되어 원래 금발 그대로입니다. 광택은 0% 무광 ~ 100% 유분 피부(기본 30%, 실제 피부 수준), 재질은 비금속 + 간단한 피하산란 보정.
- **기타**: 조명 프리셋 5종(HDRI 대신 RoomEnvironment 환경광 + 스튜디오 3점 조명 + 소프트 섀도), 밝은/어두운 배경, UI 숨기기(H 키), 전체 화면, 2~4배 해상도 스크린샷, 동영상 녹화, 텍스처 해상도 선택, 자동·고사양·저사양 품질, 로딩 진행률과 오류 안내.
- **GLB 내보내기**: 현재 리그를 GLB로 저장합니다. 스킨, 모프 50개, 안구, 치아, 혀, 구강, 텍스처가 모두 포함됩니다. 포함된 `assets/serene_face_rig.glb`(22MB, 희소 모프 + JPEG 텍스처 2K)도 이 기능으로 만든 파일입니다. 다른 엔진에서 쓸 때는 `JawPivot` 노드 회전(x축, 최대 0.40rad), `OralCavity`의 `jawOpen` 모프, 눈 노드(`EyeLeft`/`EyeRight`)를 직접 구동해야 합니다.

## 6. 검증 내역

검증은 헤드리스 Chrome에서 했습니다. 실제 GPU가 없어 SwiftShader 소프트웨어 렌더러를 썼습니다.

- 원본과의 외형 비교: 원본 FBX를 Blender로 렌더링한 이미지와 비교했습니다. 얼굴형, 헤어, 텍스처가 유지되었습니다.
- 15개 표정과 각 모프의 실제 메시 변형을 확인했습니다. 삼각형 늘어남을 자동 측정해 입꼬리 안쪽 주름에서 생기던 찢어짐을 찾아 고쳤습니다.
- 한국어·영어·일본어 문장에서 비즘 시퀀스와 입 모양이 바뀌는 것을 프레임 단위로 확인했습니다(무음 미리보기 경로).
- 눈 깜빡임과 시선, 표정 전환, 360° 회전, 모바일 화면(390×844, 터치, 패널 서랍), 캘리브레이션, GLB 내보내기와 다시 불러오기를 확인했습니다.
- 단일 HTML 파일을 file:// 로 열어 동작을 확인했습니다.

## 7. 기술적 한계 (솔직한 안내)

| 한계 | 원인 | 해결 방안 |
|---|---|---|
| 브라우저 음성은 **근사 립싱크**입니다. | Web Speech API는 음소 타이밍을 주지 않고, 단어 경계 이벤트도 음성마다 다릅니다(일부 클라우드 음성은 없음). | '타이밍 보정' 슬라이더로 맞추거나, 정확 모드(오디오 + 비즘 JSON 또는 외부 TTS)를 쓰세요. |
| 브라우저 음성은 캔버스 녹화에 소리가 들어가지 않습니다. | 브라우저가 speechSynthesis 출력을 스트림으로 내주지 않습니다. | **'⦿ 탭' 녹화**를 쓰고 '탭 오디오 공유'를 선택하세요. 오디오 파일, 외부 TTS, 마이크는 캔버스 녹화에 소리가 함께 들어갑니다. |
| 한국어 음성이 없으면 무음 미리보기로 재생됩니다. | OS나 브라우저에 한국어 음성이 설치되어 있지 않은 경우입니다. 이번 검증 환경(헤드리스 Linux)에서도 음성이 없어 **실제 소리 재생은 확인하지 못했습니다.** | OS 설정에서 한국어 음성을 설치하거나 외부 TTS를 쓰세요. |
| 일본어 한자는 읽기를 근사합니다. | 사전 없이 한자 읽기를 알 수 없습니다. | 가나로 입력하거나 외부 TTS(정확 모드)를 쓰세요. |
| 블렌드셰이프는 절차적으로 생성되었습니다. | 아티스트가 손으로 조각한 FACS 세트가 아닙니다. 주름(wrinkle map)이나 근육 볼륨 시뮬레이션은 없습니다. | GLB를 Blender로 가져가 개별 모프를 다듬을 수 있습니다(이름은 ARKit 규격). |
| 눈은 3D 안구로 교체했습니다. | 원본 눈은 피부에 그려진 그림이라 시선을 움직일 수 없었습니다. | 홍채 색과 동공 비율은 원본에서 샘플링했지만 픽셀 단위로 같지는 않습니다. |
| 60FPS는 실제 GPU에서 측정하지 못했습니다. | 검증 환경에 GPU가 없었습니다. | 자동 품질 모드가 실행 중에 FPS를 재서 해상도와 그림자 품질을 낮춥니다. |
